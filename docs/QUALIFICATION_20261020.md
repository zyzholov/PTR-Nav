## 2. CPU/GPU 结果及其限制

证据目录：`results/probability_qualification_20261020_initial/`。
`qualification.json` 保存概率源码SHA256、执行器SHA256、参数、设备和各数组摘要；
每个 `.npz` 保存输入、掩码和两后端完整概率切片。

设备为 RTX 5060；栅格 `104 x 104 x 36`，0.2m 分辨率。
CPU 单次约296至447ms；概率计算阶段 GPU 热调用约70.7至74.4ms，首次平地调用约1319ms。
这不是整链8Hz达标证明，也不是统计稳态P95/P99。
JSON 中 `accepted=true` 只对应该执行器的数值语义和125ms概率阶段门槛，不表示导航合格。

| 输入 | 中心输出 | 可以支持的判断 |
|---|---|---|
| 平地 | 上界约1.9613% | 单姿态低于5%，但不能推出整段路径预算内 |
| 坡度0.5rad | 沿坡约2.3518%，横向100% | 车辆俯仰/侧倾界限不同，方向能够改变约束 |
| 0.25m跳变 | 100% | 该解析台阶未被平面拟合抹成安全斜坡 |
| 缺支撑 | NaN | 缺测不补成零风险 |
| 无地面支撑但有柱 | 100% | 已知占据仍能阻挡，不被未知地面掩盖 |

本版本 `var=1e-4 m^2`、额外标准差下限0.005m时，即便平地也得到约1.96%的最坏界。
多个不同离散姿态累计后可能超过局部0.10预算；搜索基元还可能重复计数边界事件。
这暴露了可用性问题，不是通过调大预算或调小方差就能证明解决。
需要可验证的相关误差结构、事件复用和保守性验证，不能声称现模型已校准。

模型标准差、名义95%总区间宽度、概率上界与固定图例。

## 9. 实际足迹预算、高程曲面与短程到达资格

本节是小规模工程资格检查，不是论文批量实验或新方法对比。
仍采用显式、固定且可撤销的仿真初始支撑假设，实车关闭；GP候选不进入导航。

### 9.1 两个影响可用性的模型修正

条件分支原来采用 `|r_i|<=h/2`，这比真正的残差跨度约束严格。
现改为全部成对差 `|r_i-r_j|<=h`，严格对应 `max(r)-min(r)<=h`；
俯仰、侧倾、内部台阶、碰撞与未知拒绝不变。原始共享来源先合并再传播，不假设格子独立。

上游给出的共享高程包络按实际足迹/台阶源集合计算，下游旧实现却给整个外接正方形收费。
现统一两端集合，正确转换世界Y/X与原生环形下降X/Y偏移；重复源仍取最大尾界。
例如0.2米栅格、5度切片的内部模型实际33格，而外接方形49格，额外16格原来会消耗制动预算。
这不是抬高风险预算，也不是用安全评分替换概率。

`results/conditional_span_qualification_20261020/`保存单个104×104×36解析场景：
28个初始假设格、284个原始来源，CPU/CUDA有效域一致，最大概率差约2.79e-8。
GPU首次约423ms，三次热调用17.6至19.5ms；CPU该次约2.11秒。
这些不是长期P95，也不意味着CPU后备能够实时导航。

### 11.23 实测回波历史的限定资格试验

新增 `GroundEvidenceHistory`，默认关闭，只允许仿真显式启用且最长2秒。
