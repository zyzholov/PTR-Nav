# NEOS / 倾斜 MID360 的模块启动

当前多动态修订仍未通过完整资格。最近六物体测试仍发生碰撞并超时；历史三物体通过属于其各自冻结版本，不能继承为当前代码的通过。当前修复、计算诊断和逐次原始数据见[11 月 13 日资格记录](MULTI_DYNAMIC_NAVIGATION_STATUS_20261113.md)。其中 0.04 秒响应只作显式诊断，默认预设仍为 0.20 秒。

此预设供本地 Isaac 资格检查使用，**不是实车部署配置**。它显式选择共享 GP、固定起始支撑假设和逐格独立的 5 mm 高斯误差余项。概率量是条件模型下的几何超限上界，尚未做实地概率校准。车辆尺寸与转弯几何见 [NEOS 适配记录](NEOS_MODEL_QUALIFICATION_20261105.md)，逐次失败也保留在那里。2026-11-09 的采集时钟修正及当前资格见[本轮记录](NEOS_SOURCE_CLOCK_QUALIFICATION_20261109.md)；旧源龄没有计入一帧实际采集时延，历史通过不能直接继承。

11 月 12 日显式预设目前采用 5 m 方形后验半宽、全部已准入域的完整几何精算、1.5 m 全局基间距和 CUDA 联合动态风险模式，选择仿真观测重复性参数及 0.20 s 响应假设。未分类紧凑物体的接近速度为 0.60 m/s，普通跟踪与动态动作共用；已有当前确认运动身份使用完整运动后验参与动作筛选，包括减速/静止阶段，不删除其未来风险。总状态/制动上限仍为 5%、路径上限仍为 10%。最新三物体变速场景 45.505 s 到达并停车，风险图 5.38 Hz、最近动态间隙 0.666 m，完整资格通过；六物体持续反向仍碰撞并超时，**复杂多动态导航尚未达标**。逐次源码、结果及局限见[11 月 12 日记录](MULTI_DYNAMIC_NAVIGATION_STATUS_20261112.md)。

11月11日显式仿真预设把地形处理上限设为10 Hz；这是调度上限，实际接收频率随场景负载变化。仿真参考执行器的减速度1.2 m/s²、转角速率4 rad/s与本轮控制模型对齐，0.20秒响应仍是仿真假设，未作为实车标定。转向身份标签记忆为5秒，但可执行预测的0.6秒时效不变；5秒标签不能授权使用旧预测。风险余量排序权重为1，不能代替最终完整概率检查。

按顺序启动，每个终端只负责一个模块：

```bash
# 终端 1：物理仿真。下面是本轮使用的柱阵场景；不自动设置目标点。
scripts/sim/start_simulation.sh navigation_profile:=neos_joint_sim \
  --scene-profile light --map-asset none --nav-test-scenario boundary \
  --boundary-spec scripts/sim/experiments/boundary_cases/dense.json
```

```bash
# 终端 2：FAST-LIO2 与 FreeDOM 静态建图辅助；不单开建图 RViz。
scripts/sim/start_mapping.sh navigation_profile:=neos_joint_sim
```

```bash
# 终端 3：GPU 地形前端 → 共享 GP 地形后验 → BGK/SEB；打开唯一的 RViz。
scripts/sim/start_terrain_analysis.sh navigation_profile:=neos_joint_sim
```

```bash
# 终端 4：SE(2) 规划、前段/制动概率检查、hybrid 跟踪控制。
scripts/sim/start_planning_control.sh navigation_profile:=neos_joint_sim
```

等规划终端出现 `fused_map ready` 后，在 RViz 用 **2D Goal Pose** 设置柱阵另一端的最终目标。无需中间目标。上述场景是平路柱阵，不包含动态障碍；不会因启用预设而偷偷改变环境或给出预设路线。关闭时先停规划终端，再停地形、建图与仿真。

`navigation_profile:=neos_joint_sim` 必须在四个终端分别给出，不依赖跨终端环境变量。预设定义在 [neos_joint_sim.json](../scripts/sim/config/neos_joint_sim.json)，单个显式参数放在后面可以覆盖；未选择预设时，原默认行为不变。实车脚本不会读取这个预设。地形前端有 CPU 路径；联合动态风险须显式选择 `live_motion_prediction_model:=gaussian_joint_cpu` 才使用 CPU，CUDA 模式不可用时拒绝许可，不会静默回退。GPU 的时效结果不能移用于 CPU 模式。

11月9日预设使用 `fsgp_processing_executor:=single_ingress`：ROS执行器接收输入，唯一计算线程处理最新一张图，不排队累积。输入接纳窗口0.16秒，并按近期服务时间提前跳过预计无法交付的旧帧，编码后仍按原始源龄接纳，输出期限0.30秒、交付预留0.015秒。细碰撞格与边界在GPU构建，原始XY、地面判据、2厘米回波边界和向外取整与CPU一致；GPU失败保留CPU路径。它们没有改变车辆尺寸、膨胀、概率预算或未知区域策略。

如需用 Mars 场景，在终端 1 去掉三个测试场景参数，显式设置 `--scene-profile mars_gale`；这是另一种工作负载，不能把轻量柱阵的频率和通过结果当作全量 Mars 渲染的资格结果。相机默认不启用，建图使用倾斜 25° MID360 和外置 `/imu/data_raw`。

## 可视化各层的含义

共享 RViz 右侧下拉框可切换风险、高程、累计点云和观测来源。高程显示区分真实测量与可用于导航的补全；导航概率图贴合选定高程表面，规划仍在 SE(2)。GP 仅在既定局部查询域内输出后验，域外的 NaN 不表示原始累计建图丢失；原始点云与实测高程分别保留。

主视图的珊瑚轮廓表示实测占据集合的边界，不是车辆膨胀范围；实际竖直高度看点云。渲染器可用 `occupied_display_style:=cells` 切回逐格立体诊断。编码后仍核查原始源龄，不会让过期地图冒充新数据。异步编码候选因实测退化已撤回，当前没有对应启动参数。

风险图的航向切片表示 **整车放在该姿态时** 的约束，不是原柱体半径；粉红轮廓表示原始实体占用。黑/灰缺测处不能当作安全通道。补全不负责把柱体内部、真实坑洞、越界或证据不足的区域涂成可通行。累计点云数、实测格、补全格、源龄、当前控制状态和所用假设可在状态面板查看。

## 定向检查与当前限制

以下11月8日及更早的数字保留为历史记录，均早于采集时钟修正，不是当前版本的资格。当前逐项结论见[11月9日记录](NEOS_SOURCE_CLOCK_QUALIFICATION_20261109.md)。

当前GPU细碰撞格版本同一柱阵三次独立冷启动完整通过，源码在三次运行中保持冻结。清单为 `log/neos_subcell_cuda_dense_stability_20261108/qualification.json`。到达/停车为46.930、43.435、40.435秒；第一排整车通过为26.675、16.225、17.865秒；风险图接收频率5.45、5.64、5.46 Hz，最大接收源龄均≤0.30秒。第一轮入口切换过一次、进场距离5.74米，仍需改善；这不是随机成功率，也不是硬实时保证。独立原生回放显示，把运动粗格改为固定世界原点并不能一致减少静态误报，因此该候选没有进入运行代码。最新动态清理与台沿复核以资格记录为准。

当前GPU版横穿清理27.65秒到达、累计0.51秒持续清理达标；三动态组合46.185秒到达，风险图分别5.33/5.91 Hz。6厘米台沿仍超时：该次时效/定位合格，但一个待确认格使接触足迹支撑不完整，不能按已解决处理。监视器遗留的0.35秒源龄值已改为约定的0.30秒；六次原始逐帧样本的收紧复核见 `log/neos_strict_deadline_review_20261108/review.json`，保留原始检查报告不覆盖。

11月7日新增稀疏真实回波恢复后，初始被遮挡地面的概率支撑约0.99秒恢复，但累计点云仍约3.59秒才清理达标，完整任务证明切换也未通过；不能把累计点云清除等同于地面已测安全。高台阶检查没有越障或已确认碰撞，但持续侧向找路，未满足结束搜索并停车的要求，仍记失败。完整失败、修订和未覆盖能力见 [NEOS 资格记录](NEOS_MODEL_QUALIFICATION_20261105.md)；请勿把不同修订、被动抓取诊断和独立资格合并为成功率。

另一个“先已测地面、再实际横穿”检查通过了四秒近场恢复资格：风险约0.13秒、累计点云约0.73秒持续恢复，且最终到达并停车。观察窗由1.5秒清除时限、2秒持续确认和0.5秒发布间隔推导，完整任务时序仍归档；这不能解释为远处历史位置始终保持同一GP概率证明。新配置中累计点云以2 Hz发布，FAST-LIO2配准与降采样没有随此修改。

本轮检查保留 10 cm 台阶、10° 坡度、单次 10 cm 平面保护余量和状态/路径/制动风险预算。固定起始假设不随车移动，离开后退休；没有已测或合格预测支撑的倒车仍会被拒绝。终点位置到达与停车的资格不等于终点航向、任意地形、高速、多动态障碍、概率校准均已通过。正式批量和消融实验仍需先审阅协议。

仿真预设新增每个目标最多两次的牵引失效恢复尝试：先撤销旧轨迹并停止，确认新鲜输入、当前足迹支撑和连续0.5秒实际停车后，才重新走正常规划流程。它不会直接强制倒车或推动车辆；条件不足或次数耗尽时仍停车。通用/实车默认关闭。最新最近地面精确距离变换只优化实时障碍计算，不改变膨胀、几何或风险门槛；整链复测结果以资格清单为准。
