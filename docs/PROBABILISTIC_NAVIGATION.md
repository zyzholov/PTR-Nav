# 概率地形风险与规划控制接口

更新：2026-10-26。状态：**显式仿真假设下已有定向到达及安全拒行记录；全场景导航尚未验收，正式批量实验仍待审阅。** 最新传感器、正占据/负地形、净空及动态制动修正见[本轮资格记录](NAVIGATION_COMPLETION_QUALIFICATION_20261026.md)。第 12 节描述当前共享分支；前面的边际模型仍用于兼容。研究贡献和后续实验见 [验证主线](RESEARCH_AND_VALIDATION_PLAN.md)。

## 1. 原链路的问题与这次边界

原来的 `risk` 是坡度、台阶、支撑比例等归一化后加权的分数；`bgk_var` 包含邻域高程起伏，并非 GP 后验方差。规划器又将分数变成 8 位代价。这个链路可以做几何避险，但不能据此声称“失败概率不超过 5%”。

现在保留旧分数供兼容/诊断，新增独立的概率分支：

```text
FAST-LIO2 点云/里程计
  -> terrain_analyzer：高程均值、测量/融合方差、实测来源
  -> fsgp_bgk_se2 内部：
       BGK/原 SEB 分数（保留，不冒充概率）
       方向相关几何约束 + 高程不确定性传播 -> 概率上界
       当前点云立体障碍 -> collision_risk（确定性碰撞约束）
  -> terrain_nav：状态概率门限 + 候选路径联合风险预算
  -> 跟踪控制：新地图复核 + 当前指令制动包络联合风险预算
```

新增的是**给定高程误差模型及占据观测时，离散车辆姿态违反几何约束的概率上界**，不是标定后的实车碰撞、翻覆或陷车概率。轮胎打滑、土壤承载力、悬架、定位偏差、连续扫掠碰撞均不能仅由这张概率图保证。

## 2. 随机变量和方差的含义

对某一离散姿态 `q=(x,y,theta)`，在扩张后的车体足迹上取得不同栅格的高程：

\[
 H=(H_1,\ldots,H_n)^T,\quad E[H]=\mu,\quad
 \operatorname{Var}(H_i)=v_i.
\]

默认来自实测 `elevation` 和 `var`，计算时使用

\[
 \tilde v_i=\gamma v_i+\sigma_0^2.
\]

`gamma=probability_variance_scale`，`sigma_0=probability_height_std_floor_m`，单位分别为无量纲、米。默认 `1.0`、`0.005 m` 是待验证工程参数，不是用当前测试集拟合的校准结论。缺方差、负方差、NaN 不能补成零不确定性。

这里假设误差联合高斯，边际均值/方差描述有效。未假设不同格子独立。上游滤波可能低估边际方差，固定下限也不能消除模型偏差，因此尚需独立数据资格验证。

## 3. 方向几何量怎样变成线性随机量

车辆前后各 `0.42 m`、半宽 `0.313 m`、额外余量 `0.10 m`，地形与规划配置已对齐。保守枚举与旋转矩形足迹相交的栅格（允许多包含，不少包含），取实际栅格位置。不能把落在同一格子的两个样点当两次独立观测。确定性碰撞分支也覆盖相交栅格，而不只检查25个离散足迹点。

用车辆坐标下实际栅格位置构建设计矩阵：

\[
 X_i=[x_i^b,y_i^b,1],\quad B=X^+,\quad
 [a,b,c]^T=BH,\quad r=(I-XB)H.
\]

俯仰和侧倾用 `atan(a)`、`atan(b)` 表示。由于 arctan 单调，对应约束为

\[
 |a|\le\tan\phi_{\max},\qquad |b|\le\tan\rho_{\max}.
\]

非平面起伏的离散约束为 `max(r)-min(r) <= h_max`。旧版逐残差使用充分条件
`|r_i| <= h_max/2`；新版保留这个保守界作为候选，同时直接为残差跨度建立高程误差包络。
这仍是离散几何代理，并非真实底盘接触通过能力的充分动力学证明。

**台阶不能只靠平面残差判断。** 平面拟合可能把台阶拟合成斜坡。因此还对足迹样点附近的 X/Y 边使用四点差分：

\[
 d=(H_1-H_0)-\tfrac12[(H_0-H_{-1})+(H_2-H_1)],
 \qquad |d|\le h_{\max}.
\]

连续平面及二次曲面在该差分中抵消，孤立高度跳变被保留。它是离散台阶几何代理，不是接触动力学仿真。四点差分需要足迹附近额外一至两格支撑；邻域不足时保持未知。

仅在显式仿真起始假设模式下，使用契约4：台阶采用足迹内部连续三格的
`H_{-1}-2H_0+H_1`，同时保留俯仰、侧倾和残差约束。三点式抵消平面，
**不抵消二次曲面**，因此它不是契约2四点式的等价加速版，曲率处可能更保守。
这样不要求起始足迹之外的未知格成为假设支撑；跨格台阶回归仍要求拒绝。

## 4. 从均值/方差到越界概率上界

上面的每个量都写成 `G=w^T H`，其均值 `m=w^T mu`。完整协方差不可得时：

\[
 \operatorname{Var}(G)=w^T\Sigma w
 \le \left(\sum_i|w_i|\sqrt{\tilde v_i}\right)^2=s_{\rm ub}^2.
\]

这是 Cauchy-Schwarz 上界，允许共享配准误差等相关性；没有把逐格方差当成对角协方差来伪造高置信度。

对双侧约束 `|G|<=L`，当 `|m|<L` 时：

\[
 u_G=\Phi\!\left(\frac{-L-m}{s_{\rm ub}}\right)
      +\Phi\!\left(\frac{m-L}{s_{\rm ub}}\right).
\]

在均值位于界内时，该越界概率随方差增加，所以上式是高斯假设下的上界。**均值已越界时直接取 1**，不能继续套“增大方差会更保守”的错误推断。

把俯仰、侧倾、残差和台阶事件取并集可得到第一个有效上界：

\[
 P(E_q)\le U(q)=\min(1,\sum_j u_{G_j}).
\]

并集上界不要求各事件独立。它可能很保守；高不确定性的地形应拒绝或重新观测，不能为了获得可走路径偷偷降低方差或放松风险预算。

### 4.1 共享高程误差事件（契约2）

不能把重叠足迹当作互不相关的新危险重复收费。令真实高程误差
`e_i=H_i-mu_i`，标准差为 `sigma_i`。若所有所需地面格满足
`|e_i| <= t_q sigma_i`，则一个线性几何量的误差满足：

\[
 |w^Te|\le t_q\sum_i|w_i|\sigma_i.
\]

因此令 `t_q` 不超过所有俯仰、侧倾和四点台阶约束的标准化剩余裕量。
对残差跨度，设 `R=I-XB`，使用

\[
 C_R=\max_{i,j}\|R_i-R_j\|_1,\quad
 t_q\le\frac{h_{\max}-(\max R\mu-\min R\mu)}{C_R\max_i\sigma_i}.
\]

负裕量截为0，相应尾概率为1。若上述包络成立，所有离散几何约束均成立，
故失败包含在至少一个高程误差越过包络的事件中。单个边际事件的上界为
`tau_q=2 Phi(-max(t_q,0))`，姿态上界可取
`min(原特征并集界, 所需地面格数 * tau_q, 1)`。
两个界都针对同一几何失败事件，取较小值不需要独立性假设。

一条路径中同一个地面格若参与多个姿态，采用**最大尾概率**（最严格包络），
不重复累加。规划器按与上游相同的足迹栅格及实际台阶差分支撑集合收费，
而不再给整个外接正方形收费。默认四点式仍包含足迹之外的差分格；
契约4仅含足迹及内部三点式格。原方形半径层保留用于完整性验证，不代表所有窗口格都应计费。
原生环形缓冲的行/列是下降X/Y，世界阵列行/列为上升Y/X；偏移必须交换并取负。
这是有明确条件的高斯模型上界，不是实车安全概率校准，也不是放宽预算。

已证实的占据格与当前足迹相交时，该地图模型中的碰撞约束已经违反，输出上界直接为1，即使障碍下方地面未知也不能把柱子显示成低风险/无风险。其余位置若几何支撑不足仍输出未知，不把“未看见柱子”等价为“已证实安全”。当前点云和实时碰撞检查仍单独保留。

### 4.2 直接残差跨度的第二种证明（2026-10-21）

原来的 `|r_i| <= h_max/2` 比物理代理条件 `max(r)-min(r) <= h_max` 更强，
会额外拒绝不对称但跨度仍小的残差。保留原有上界，另外利用恒等式

\[
 \max r-\min r\le h_{\max}
 \iff \forall i<j,\ |(R_i-R_j)H|\le h_{\max}.
\]

每个差值仍使用第4节的相关性无关方差上界及高斯双侧尾概率。
将所有成对差值的尾概率与俯仰、侧倾、原台阶差分尾概率相加，得到另一个有效上界
`U_pair`，没有改变台阶阈值、观测方差或状态/路径/制动预算。
GPU仅在旧界 `U_old > 0.005` 且均值跨度未越界的格子运行较贵的成对计算；
采用 `min(U_old, max(0.005, U_pair))`，其余保留旧值。
`0.005` 是额外证明的保守计算门槛，不是风险预算，也不把原有更低风险抬高。
这个表达在工作门槛处连续，并保持固定均值下对方差的单调性。
每个候选都是同一事件的有效上界，取最小值不需要独立性。
CUDA逐项累加到已无改进可能时提前退出；CPU参考实现保留完整矩阵计算。

GPU进一步按相同格点位移分组复用。令 `d=(X_i-X_j)B`，则残差差值权重为
`e_i-e_j-d`，其相关性无关标准差界精确重排为

\[
 s_{ij}=\sum_k|d_k|\sigma_k
       +( |1-d_i|-|d_i| )\sigma_i
       +( |-1-d_j|-|d_j| )\sigma_j.
\]

相同位移的格子对共享第一项；后两项只需常数次运算，均值复用已算残差。
这不是改成更松的近似，也不是去掉相关性。CUDA另外给标准差加极小正数舍入裕量，
独立异方差回归覆盖全部36个方向。耗时只按归档输入单独记录，不拿它冒充全链路延迟。

这只减少充分条件造成的冗余，不证明地形本身安全；未知支撑仍为NaN，
明确占据仍为1，台阶事件仍独立保留。背景SGPR的算子表示兼容修复也不参与降低
当前帧导航方差：优化预测策略遇到等价Sum算子时改用同一核/似然的通用条件化，
保留完整先验对角修正；CPU/CUDA均与独立高斯条件化方程回归核对。

## 5. SE2Grid 数据契约

输出话题仍为 `/car_0_fsgp_bgk/fused_map`，保留坐标、环形缓冲布局、输入时间戳；方向切片中心为 `(k+0.5)*2*pi/N`。

| 层 | 维度 | 含义 |

| `probability_front/back/half_width` | 2D常数 | 含余量的足迹尺寸，单位米 |
| `probability_max_pitch/roll/step` | 2D常数 | 建图采用的几何界限，单位弧度/米 |

打开诊断层后另输出俯仰/侧倾/台阶概率上界与足迹支撑比例。支撑比例只是有效样点比例，不是安全概率。除已知占据可直接判阻挡外，实际 `probability_valid` 要求完整差分邻域；仅由占据判阻挡的姿态不伪造有效的俯仰/侧倾分量。

GPU 前端新增 `ground_observed`：清除动态物体后由邻域恢复的地面不是实测，默认不用于概率支撑。新真实测量到来后重新初始化该格的测量融合，不把恢复值当作独立观测先验。关闭 `verbose` 也必须更新高程/方差，不能只更新风险切片。

历史条件源仅是显式仿真资格选项 `probability_ground_history_s`，默认0、上限2秒。
只有原始时间已和实测地面一致的XYZ才能入库，预测和起始假设都不能入库；
遮挡不刷新源时间，新占据/可靠实测冲突/原始坑阶证据会撤销对应源。
后续未知处仍须经过同一局部GP、距离、包围域、方差及足迹/制动检查。
这不是随车扩张的安全区，也不是将旧回波重标为当前测量。

在固定本次核参数与条件权重的模型下，局部通用克里金的条件均值为
\(\mu_*=w^Tz\)，其中
\[
 A=F^TK^{-1}F,\quad d=f_*-F^TK^{-1}k_*,\qquad
 w=K^{-1}k_*+K^{-1}FA^{-1}d.
\]
同一邻域索引与权重直接用于历史误差传播，不重新运行一次近邻搜索。
若源年龄为 \(a_i\)，明确采用时间漂移标准差模型 \(\kappa a_i\)，
在不假定源间独立的条件下按三角不等式取
\[
 s_{\rm drift}\leq\kappa\sum_i|w_i|a_i,\qquad
 \sigma_{*,\rm aged}=\sigma_{*,\rm GP}+\kappa\sum_i|w_i|a_i.
\]
这里的 \(\kappa=0.01\) 米/秒是当前资格模型，不是实车标定结论。
不能用 `max(age)` 替代带绝对权重的和：GP权重可能为负且绝对值之和大于1，
旧表达此时反而低估传播误差；远处旧源权重很小时又会过度保守。
`gp_conditioning_age` 仍单独报告最旧条件源年龄，不把加权年龄冒充数据更“新”。
以上仍条件于已学习的模型及漂移假设，不包含完整的超参数估计误差或实车概率校准证明。

### 5.1 显式仿真初始支撑假设

默认仍为 `startup_support_mode=unknown`，实车不得打开此假设。用户仅批准在仿真验证
`stable_stance`：静止姿态持续1.5秒，周围0.65至2米至少24个实测地面格，
凸包包围起点；局部平面绝对残差P95不大于5厘米、坡角不大于0.2弧度，
并检查Hunter车体离地高度。初始足迹固定在世界坐标，不随车扩张。
锚点使用真实初始位姿，不吸附最近格心；再保守枚举与固定足迹相交的格子。
吸附格心会把足迹平移最多半格，漏掉原本相交的一侧，不能代替栅格化。
固定栅格足迹包含稳定性检查允许的初始航向抖动范围 `±0.025 rad`，
避免接近零度时因0/2π切片边界造成支撑闪断；该范围锚定后不随车转向增加。
新观测高度偏离6厘米或出现占据会撤销；仿真时间回退重新初始化。
锚定之后无需新里程计来重新证明固定位置，但仍检查当前地图；规划器的里程计/地图时效看门狗保持开启。

这些检查只能使假设与已有观测一致，**不能证明传感器盲区真实安全**。
未见凹坑、细障碍或软土仍可能推翻假设。模型误差下限0.005米亦未经校准，
不能据此声明实车失败概率或95%实际覆盖率。

为避免把同一平面派生的格子当作独立测量，保留平面来源权重。
设周围原始测量为 `Z`、平面系数 `C Z`，假设格为
`H_j=[dx_j,dy_j,1] C Z + epsilon_j`。对几何量 `w^T H`，
先合并共享来源的系数，再对每个来源的绝对权重乘标准差求和：

\[
 s_{\rm ub}=\sum_i\left|\sum_{j\in A}w_j D_j C_{:,i}\right|\sigma_{Z_i}
       +\sum_{j\notin A}|w_j|\sigma_j+\sum_{j\in A}|w_j|\sigma_0.
\]

`A`为当前使用初始假设的格子。该式不依赖测量之间或与模型误差之间的独立性；
显示边际标准差也按三角不等式合并。残差跨度改用全部成对差值：

\[
\max r-\min r\le h_{\max}
\iff \bigcap_{i<j}|(R_i-R_j)H|\le h_{\max}.
\]

逐对传播上述共享来源，和俯仰、侧倾、内部台阶作并集。这与原物理跨度阈值一致，
不再额外要求每个残差绝对值小于半阈值；阈值、测量方差及风险预算均未放宽。
姿态总上界和原共享高程界均有效时取较小者；路径中条件姿态事件独立编号，重复事件取最大上界，
不同姿态仍求和，不假设独立、不把启发式分数冒充概率。

另保留一项充分条件：取由后验残差均值确定的固定中心
`c=(max(E[r])+min(E[r]))/2`，若所有 `|r_i-c|<=h_max/2`，则残差跨度必不超过
`h_max`。各残差仍按上述共享来源传播标准差；其越界尾概率和，及全部残差对
差值的尾概率和，是同一个跨度事件的两个有效上界，可取较小者。
俯仰、侧倾、内部台阶项在两种证明中均保留。中心不能用未知的真实误差选择。
CPU与CUDA使用同一公式；这不是将粗糙度阈值调大，也不依赖误差独立。
外部台阶差分模式不启用这个只覆盖内部差分的条件证明。

条件姿态还可保留原先完整的边际高程包络：只有地图同时给出有效的绝对误差半径、
方差及尺度时，规划器才允许复用该来源证明。整条路径分别维护完整账本，
取有效总上界的较小者；没有把多个不同条件姿态简单视为一个事件。
有效证明更紧不代表该路径必然能通过，仍需满足状态、路径和制动三项预算。

初始条件姿态无法立即承担整条路径预算时，只尝试朝原目标方向的已检查直行短前缀
（至少0.25米、最多1.2米）；保留原始目标，滚动重规划。
对于与车头夹角0.15至0.65弧度的斜前方目标，额外允许最多0.40米的已验证直行观察段；
用相切圆曲率 `2*abs(y)/(x*x+y*y)` 检查直行之后仍保留20%转向裕量，
不足0.25米时不再继续该前缀。它不是预先批准未知弯路，只避免在原地反复搜索；
后续曲线、车体碰撞与概率预算仍必须重新验证。
只有当前完整足迹、确定性碰撞和局部联合预算同时通过才提交，
每周期仍检查制动包络。固定起点1.5米范围内最高0.25米/秒；未知前方不会因这项假设而放行。
这不是全方向探索策略，也不等于已证明复杂动态环境中的普遍绕行成功；
已通过的短时横穿停车/再行驶实例及失败记录见资格记录11节。

仿真验证须在两端显式允许，不能只开一边：

```bash
scripts/sim/start_terrain_analysis.sh terrain_backend:=gpu fsgp_gpu_backend:=cupy startup_support_mode:=stable_stance
scripts/sim/start_planning_control.sh chance_allow_startup_prior:=true
```

两个命令分别在建图已经启动后的独立终端运行。只在风险图中显示假设、或者短时发出非零指令，
都不等于到达测试通过，见资格记录中的失败实例。

条件姿态事件在相邻位置仍可能重复覆盖同一批不确定来源，当前预算因此可能过于保守。
曾尝试把平面分成三个共享系数事件，但真实地图上系数包络尾概率过大，
导致完全不能起步；该试验没有通过资格检查，已撤回运行链路，不能宣称解决了导航成功率。
后续需要验证测量/配准误差的相关结构，或为共享几何特征构建可复用事件，
同时检查漏判和保守性，不能通过提高预算、伪造独立性或降低传感器方差来换取通过。

## 6. GP 补全如何衔接

默认 `prediction_backend=feature_sgp`、`gp_async=true`，后台单任务拟合/预测，
没有等待队列；缺CUDA时 `gp_device=auto` 可使用CPU。
候选显示来源年龄上限2秒，整数格地图移动只重排已有预测，新进入窗口的条带仍未知。
后台预测不修改实测高程，当前碰撞观测会清除该格候选标记。

2026-10-20修订：`scripts/sim/start_terrain_analysis.sh` 默认启用当前帧条件补全；
`prediction_backend:=none` 自动关闭补全，`gp_complete_supported:=false` 可显式禁用。
通用节点/YAML仍默认关闭，实车不自动批准。仿真规划入口允许GP契约；
`use_sim_time:=false` 时该许可默认关闭。补全不是直接放行，还必须通过原风险预算、
车辆足迹、硬碰撞与每控制周期的制动包络检查。

后台SGP候选仍只用于展示/诊断。导航另用独立的局部条件GP实例：只从**当前点云确认过的
实测地面格**取训练点，仅查询缺测且距当前支撑不超过配置上限的格，默认0.35米。
距离按与实测格高程一致的**当前真实回波XY**计算，而不是将回波移到格子中心。
20厘米栅格上的中心化可能把实际0.317米距离变成0.400米，制造支撑断裂。
训练仍每格一个高程估计，没有把同格多个回波当独立样本来缩小方差；
此距离修正不增加假设区域、不放宽0.35米范围，也不允许隐藏格回波进入训练集。
要求局部二维包围、几何可辨识、预测标准差不超过0.04米；单侧外推、过期、方差无效不放行。
`probability_gp_max_age_s=0.25` 检查当前重条件化所用点云源时间，不刷新后台旧拟合时间。
源时间差先按ROS整数纳秒相减，再转换秒，避免同一时间戳产生负浮点舍入误差；
真实的未来帧仍不用于条件补全。
通用显示模型默认20个最近邻；导航专用实例当前使用64个。近邻若全在查询点一侧，
会漏掉同一半径内已测到的另一侧孔洞边缘。
导航局部GP在这种情况下按8个角扇区保留最近实测点，再补足最近邻，
总邻居数不超对应实例的配置、半径仍不超过1.5米。原本包围查询点的近邻集保持不变。
这只是观测选择，不能放宽凸包、可辨识性、标准差、当前点云证据或后续风险门槛。
缺测位置的真实回波只可否决预测（如低台阶/坑洞），绝不作为隐藏位置的训练高程。
已确认硬障碍不允许补全；旧启发式未知分数0.65不再冒充已确认障碍。
实测高程/方差不改写，也不把相关的预测与实测按独立高斯相乘。

对应输出为 `gp_completion_mean/variance/age`、`probability_gp_used` 和
`probability_elevation/variance`。后两者才是规划实际使用的地形；后台 `gp_mean` 不可代替它们。
RViz高程视图区分实测曲面、候选点、导航批准的薄荷绿格和仿真起步假设的琥珀格。
有预测均值不代表有足迹支撑，更不代表可通行，因此风险有效域仍可能小于预测显示域。

2026-10-22资格接口：`probability_gp_max_distance_m` 允许显式调整插值候选域，
默认0.35米，大于0.35仅允许仿真，上限0.75米；所有上述后验/几何及下游风险门槛不变。
地图附带 `gp_completion_nearest_m`、`gp_completion_distance_limit_m` 记录实际距离和门槛。
固定距离是候选域策略，不是安全概率证明。扩大该域是否有用、是否过度自信必须独立验证；
低模型方差不等于已完成真实误差校准，不得据单次到达直接部署实车。
最多2秒的原始地面历史同样默认关闭且仅供显式仿真资格试验，详见资格记录第11.23节。

### 6.1 潜在高程方差与测量噪声

实时分支使用二次趋势的局部通用克里金。设趋势矩阵为$F$，残差核为$K$，
测量噪声方差为$\sigma_n^2$，则$C=K+\sigma_n^2I$、
$A=(F^TC^{-1}F)^{-1}$、$\hat\beta=AF^TC^{-1}y$。
查询点的趋势向量$f_*$、核向量$k_*$给出

$$\mu_*=f_*^T\hat\beta+k_*^TC^{-1}(y-F\hat\beta),$$
$$v_*=k_{**}-k_*^TC^{-1}k_*+
(f_*-F^TC^{-1}k_*)^TA(f_*-F^TC^{-1}k_*).$$

`condition_local`另加入留一法缺拟合的非负超额项；不可辨识趋势直接拒绝。
核幅值至少为默认测量噪声方差，长度尺度与趋势均在本实现明确给定/由当前观测估计。
这里$v_*$是**潜在地面**的条件方差，新一次带噪测量的方差才是$v_*+\sigma_n^2$。
旧实现把$\sigma_n^2=0.02^2$又当作$v_*$的硬下限，造成平滑缺测带也被无谓拒绝。
现在按公式计算，不靠降低预算或人为指定小方差通过；单元测试用独立NumPy公式核对。
概率传播仍额外保留原5毫米模型标准差下限。

这是给定核/噪声模型下的条件结果，包括局部测量噪声模型假设，不是已经校准的实车置信保证。
特别是共享定位误差、地表突变、不可见悬崖和模型失配，仍需实测校准与专项验证。

### 6.2 不同方差的路径风险记账

旧共同标准化尾界会把一个高方差格的代价分摊到整个足迹。现增加**绝对误差半径**$\delta$：
对每个斜率/台阶线性约束$|w^Th|\le L$取
$\delta\le(L-|w^T\mu|)/\|w\|_1$，对残差极差约束取
$\delta\le(h_{max}-\operatorname{span}(R\mu))/\max_{i,j}\|R_i-R_j\|_1$。
满足所有来源$|h_i-\mu_i|\le\delta$即可满足这些相同物理约束。
每个来源按自己的$\sigma_i$计算尾界
$p_i=\operatorname{erfc}(\delta/(\sqrt2\sigma_i))$，重复覆盖来源取较大事件，再用联合界求和。
不需要假设相邻格独立，也不使用独立生存概率相乘。

规划器同时保留原统一尾界账本、异方差绝对包络账本、位姿联合界账本及完整覆盖的混合账本，
取有效上界的最小值。不能逐格任意挑不同证明的较小尾界，必须保证每一本账本覆盖整条路径。
保留原账本确保新增证明不丢掉旧证明能接纳的路径。状态0.05、局部路径0.10、制动0.05预算未调大。
这些是当前局部离散几何风险界，滚动重规划并不自动给出整次任务的累计风险保证。

启动默认仍为未知，不加入真值地面或跟车安全气泡。用户批准的例外只在显式
`startup_support_mode:=stable_stance` + `chance_allow_startup_prior:=true` 的仿真资格测试中启用。
固定初始支撑优先于GP，避免替换共享平面证明导致原路径退化；实测仍具有最高优先级。
大面积无支撑盲区不会被窄孔洞补全能力自动填满。

## 7. 规划与重规划

增强地形导航 launch 默认 `chance_constrained=true`。原始地形/旧配置保持显式兼容模式，不修改 FAST-LIO2 采样参数。

1. 检查概率模型版本、足迹尺寸、通过界限、预测模式、坐标系。缺层或配置不兼容即失效旧快照并停止，不回退到旧分数。
2. 点云碰撞图仍逐足迹检查；几何概率已包含足迹，只在车体中心查询，避免再次膨胀车体。
3. 直接读取浮点概率，不从 8 位代价反解概率；未知区域不使用旧“车体周围放行气泡”。
4. 状态约束 `U(q)<=chance_state_limit`，默认 `0.05`。
5. 一条**当前局部候选路径**的离散事件集合 `S(path)` 必须满足：

\[
 P(\cup_{q\in S}E_q)\le
 \min\left(1,\sum_{i\in\cup_q W_q}\max_{q:i\in W_q}\tau_q\right)
 \le\epsilon_{\rm path}=0.10.
\]

`W_q` 为实际足迹及对应台阶差分源集合。契约2复用的是**同一个地面格的误差事件**，
不是声称邻近姿态相同，更不是使用 `1-prod(1-p)` 的独立假设。
旧契约1仍采用不同格/航向的 `sum U(q)` 界。最终检查包含路径末端，按空间/航向细分，保留未知拒绝。

搜索中传播完整源事件账户，基元边界也复用同一事件；用16档风险标签保留不同预算状态。
优化代价仍包含加性的概率惩罚。事件集合不同的标签可能被近似搜索合并，
**不声称概率约束搜索完备或最优**；最终账户复核仍须通过。

直达曲线、曲线合并、平滑结果、格点搜索、近距离倒车及倒车恢复提交前均检查风险预算。新地图让路径前瞻不满足约束时，控制器停止并请求替换路径。

近距离倒车返回可参考最近记录的前进行驶走廊，优先求解同时满足起点/终点
车身朝向的反向Dubins连接；完整连接不可认证时优先保留其合格前缀，
没有合格前缀才尝试受检的反向Ackermann弧。
运动朝向与车身朝向相差pi，发布和碰撞检查始终使用车身朝向。
避免仅对准目标位置而切出弯曲走廊。记录最多256点，
里程计重置/断流/坐标系变化即清除；目标或当前位置不匹配记录时使用直达弧。
历史轨迹只提供路径几何，所有候选仍以**当前**地面支撑、立体障碍和原风险预算检查。
带目标航向的倒车Dubins连接也使用滚动前缀验证：完整连接不满足预算时，只保留
连续通过验证且确实向目标推进的前段，保留其原有车身航向演化。
位置圆弧仍是无合格航向连接时的后备候选，并非无约束放行。
每段依然受原路径与制动预算约束；
历史驶过本身不构成安全证据。
它不扩大起始假设，不把曾经驶过等价为现在安全，也不是任意多次换挡的全局倒车规划器。

当完整搜索失败但前方仍有可验证的短通行段时，尝试保留原目标的短弧前缀：
前方夹角不超过0.65弧度，弧长0.25至1.2米，曲率取朝向目标的相切圆
`2*y_local/(x_local^2+y_local^2)` 并限制在车辆转弯能力内。
该段仍逐样本通过车体碰撞、地面支撑和同一0.10联合预算，
每周期再过0.05制动预算；未知或台阶不会因路径变短而放行。
只在完整搜索失败后使用，不能把短段返回包装成已找到完整任务路径。
非终段耗尽至0.15米时发明确零速、等待新段，而非无限趋近零的“tracking”。
若认证路径终点已经进入原目标的0.22米容差，则允许执行至剩余0.02米，
仍由实际位姿进入0.25米到达圆触发完成。否则“终点容差+提前0.15米停车”
会把车辆卡在到达圆外。短倒车段已进入目标容差时也不再要求至少0.25米进展；
这只修正终端衔接，不增加未知区域许可，制动包络仍需在当前地图上通过。

**局部预算不等于整个任务失败概率。** 多次滚动重规划会产生新的局部集合，当前没有全任务风险账户；不能将默认局部 `0.10` 解释为“整段导航成功率 90%”。

## 8. 跟踪控制

当前默认跟踪器仍为 Pure Pursuit/Stanley 混合，不是 MPPI。源码审计确认旧采样分支只是选取最低代价样本，现正名为 `sampling_mpc`，不是基于重要性权重更新的标准 MPPI。

Stanley项包含参考曲率前馈 `atan(L*kappa)`，其中 `kappa=delta_yaw/(direction*delta_s)`，
前进方向为1、倒车为-1，再加航向和横向误差反馈。旧实现只有反馈项，零误差时为0，
与Pure Pursuit加权后会把正确圆弧转角乘以其权重（Hunter配置0.42），系统性转弯不足。
现在理想圆弧零误差时，两项都给出自行车模型所需转角；转向幅值、速率及制动检查保留。

`tracking_controller=auto` 按旧 `use_mppi` 兼容选择（默认 false -> hybrid）；可显式选择 `hybrid` 或 `sampling_mpc`。后者在 CPU 上运行，倒车使用混合器；候选序列满足加速度/转向速率约束，逐段碰撞和风险检查，全部不可行时直接停车。不会将无效名义序列输出，也不再对验证过的速度强加最小速度抬升。

两种跟踪器的最终输出均须检查制动包络：使用实测速率与候选速率的较大值、实际/目标转向、转向速率、响应延迟及减速度推演，要求几何/碰撞可行，并满足 `chance_braking_budget=0.05`。不满足则尝试降速，仍不满足则立即零指令并重新规划。

引导目标搜索使用规划线程捕获的目标快照，提交前核对目标序号和输入代次；
耗时搜索不持有控制端读取的目标锁。倒车恢复在停止后允许至多0.15米的有界
端点捕获偏差，以实际姿态重新验证完整前进出口。偏差过大或出口不安全时撤销
旧恢复路径并重规划。规划标记的高度优先使用实际导航高程层。

Hunter仿真运行配置的地图最大年龄为0.5秒；这包括消息到达后直到下一次更新前的等待，
不是允许生产端算完0.5秒的旧地图仍当新数据。行驶资格观察器另要求接收时源年龄最大
不超过0.35秒、GPU新图至少5Hz，并保留每条时间戳。超过运行年龄会停车等待新鲜输入，
不能靠刷新消息时间或旧GP时间绕过。

这表示速度改变了需要验证的停止范围，**不是凭空假设减速会改变静态地形的失败概率**。减速度、延迟仍为配置模型，不是实车已测制动极限。

Hunter的车体碰撞包围尺寸单独配置为前0.58、后0.48、半宽0.40米；原始地形碰撞层另加完整碰撞余量。
实时障碍层已经膨胀，额外车身余量取 `max(0, footprint_margin-live_inflation)`，
避免将同一边界再次叠加而使实际无碰撞的当前位姿锁死。
使用四条分离轴检验车身矩形与占据格相交，规划、控制和紧急路径检查保持同一几何定义。
这是确定性工程边界的调整，不是概率证明，也不允许忽略真实车身碰撞或未知足迹。
它覆盖凸出的保险杠和转向轮缘，不能缩回轮胎接地支撑模板。
该碰撞检查只查询确定性立体占据；地形概率仍使用原接地足迹，
不为保险杠下方凭空增加假设支撑。通用节点的 `body_collision_*` 默认0，表示继承原足迹。

仿真搜索终点容差为0.10米，控制到达距离为0.12米；两者都在估计地图坐标系中。
独立物理真值仍使用0.30米到达门限，不能用估计坐标系“已到达”代替实际精度验证。
场景扩展、失败和复测见[组合场景资格记录](NAVIGATION_SCENARIO_EXPANSION.md)。

`/terrain_nav/chance_status` 发布标准 DiagnosticArray（不超过5 Hz、接受/拒绝变化立即发布）：控制器名称、指令/实测速率、转向角、状态上界、已通过的制动上界、预算、地图年龄。无路径/空闲也发布状态。`NaN` 表示未获得有效数值，不能补零。输入未就绪/过期等更早的停止仍见节点日志；该话题不是独立看门狗心跳。显示端会把缺失/过期状态标出。

### 8.1 动态障碍的短时运动守卫

仅检查当前占据，会在横穿物体尚未进入行驶走廊时继续加速，等物体进来再刹车可能已晚。
新增 `GridMotionGuard` 从当前注册点云的立体占据格提取8连通分量，
对相邻时刻世界坐标质心作尺寸门控及双向最近邻关联；不读仿真障碍真值。
平移后的格子重叠须覆盖较小分量至少50%，并比不平移多出至少15%；
可见静态轮廓被裁去一部分时，不能只因质心变化就宣称物体在移动。
相邻帧间隔仅接受0.04至0.4秒，平移速度在0.5至4.5米/秒的候选
以恒速平移外推1.5秒，重用实测占据形状并加位置余量，生成临时扫掠占据。
原始关联每扫描替换，但验证过的速度可短时保持最多0.60秒，缺测/预测不能续期；
从外推的当前位置扫描未来，不累计过去的扫掠残影。真实静止重观测立即取消，
时钟回退、扫描间隔大于0.4秒、分辨率变化均清空；实时输入看门狗仍保留。
基础位置余量为一格，保持期间另按0.25米/秒的工程误差余量增长，
不是已标定的概率置信界。不把预测写入地形高程、GP或FAST-LIO累计地图。

临时占据与当前占据共同用于路径否决、制动与重规划。调试话题
`/terrain_nav/live_obstacles` 中100表示当前/短时保留占据，80表示运动守卫扩张，
**这两个值是显示编码，不是占据概率或失败概率**。
节点日志的 `moving` 是运动候选分量数，稀疏轮廓变化可能造成假运动，不能当作目标跟踪真值。
可用 `live_motion_guard_enable=false` 关闭；参数 `live_motion_horizon_sec` 控制外推时长。

这仍是短时恒平移的工程防护，不是有加速度/遮挡保证的时空碰撞概率规划器。
关联失败、轮廓变化、物体加速及更高速度仍需专门验证，不能由一次横穿通过推出动态障碍通用保证。
资格测试另外检查独立车体矩形到柱面的净空、事件后零指令延迟、连续物理停车及最终到达；
不再用一个固定起点距离段内的零指令数代表真正的事件响应。
按需 `/terrain_nav/live_obstacles_raw` 仅输出预测/持久化/膨胀前的实际柱掩码；
100为检测到柱，0为无柱观测，不等于安全地面。记录、原生重放及后验真值评估脚本见
`motion_grid_capture.py`、`motion_guard_replay`、`score_motion_replay.py`。

## 9. 可视化的科学含义

共用 RViz 继续由 `scripts/sim/start_terrain_analysis.sh` 启动，不增开规划窗口。

- 地面采用原高程几何，叠加当前车辆航向的概率颜色；不再把 BGK 平滑地面冒充原几何。
- 低风险0至1%为青绿到浅绿，5%为橙、100%为红，未知为灰；固定数值断点与侧栏图例一致。
  颜色只用于显示，低风险颜色不等于整段路线安全，判定仍读取浮点概率层。
- 灰色为概率未知，但可有实测地面几何；地面本身无值处不造三角面，也不补成安全。
- 累计点云 `/Laser_map` 采用浅冷灰，专用点云模式为3像素、透明度0.95；风险/高程模式降为1像素背景，避免遮住地形。路径为0.045 m青色线；实测轨迹为金色、恒指令运动投影为紫色。后者不是优化预测轨迹。不会增加真实点数制造“更密”的假象。
- 默认显示风险曲面，其颜色只由固定风险色标决定，不再混入高程色。高程、风险和累计点云是独立视图。
- 右侧模式选择：风险导航、实测/预测高程、累计LiDAR、实测/GP来源。高程模式显示独立的实测三角曲面及预测候选小点；来源模式中实测为青绿、候选为淡蓝紫。
- 高程曲面话题为 `/terrain_display/elevation_surface`，由C++转换器生成，只连接四角均有实测高程的相邻格，不跨空洞/大跳变，不上采样伪造细节。高程色标采用实测值2%至98%分位，范围在侧栏标出；候选使用同一色标但不并入实测面。
- 只读显示节点不再因里程计暂缺而阻止已有高程点发布；车辆轨迹/控制状态仍要求里程计新鲜。车体使用不透明持久标记、Transient Local订阅，时钟回退不会卡住发布节流，无效姿态不会覆盖最后的有效模型。
- `measured_cells` 是实际来源格数，`candidate_cells` 是背景模型接受的显示候选格数，`navigation_prediction_cells` 是当前帧条件化后实际纳入概率输入的格数。后两者可能相交，候选本身不代表导航许可，不得将这些计数相加当作“补全覆盖率”。
- 点击候选可以读取GP均值与模型区间，但该点原始 `elevation/valid` 和导航状态不变；黑色空洞可能是没有地面值、候选被拒绝或完整足迹支撑不足，不能仅用填色消除。

新增只读 `navigation_display` 与原生 `ptr_navigation_rviz/StatusPanel`：在同一RViz固定右侧栏显示控制状态、速度/转向、地图年龄及相对路径线段的XY误差；选点/车下探针显示坐标、实测来源、模型标准差与95%区间总宽，三维处保留 `+/-1.96 sigma` 区间线。
默认关闭漂浮长文字和世界图例，避免缩放后无法阅读或裁切；固定图例不受视角影响。
缺数据/控制器不可用明确显示，不将未知地面补成安全，也不修改任何导航输入。
GUI已经过真实链路及标注为录制夹具的侧栏截图检查；不能以界面可读替代动态跟踪和全部视角验收。
2026-10-21补充：默认局部Orbit跟随FAST-LIO的 `base_link`，避免车辆驶离固定世界视角；
世界总览仍作为保存视角。高程视图显示独立实测曲面与不同来源的预测点，
不会为填满画面而把大范围未知孔洞补成实测或安全。

### 12.1 为什么改变补全与风险传播

分别预测每个格子的均值和方差，会丢失同一片地面上高度误差的相关性。
例如整片地面同时抬高2厘米，不应改变坡度；逐格按最坏相关性传播，可能把它解释为局部起伏。
多个姿态的上界再累加后，平坦地面也可能无法满足路径或制动预算。
当前修改在车辆附近约6米见方的窗口中拟合一个共享随机高度场；近场之外继续使用原概率层。

训练高度只能来自前端保留的原始实测地面。车辆转弯产生的当前扫描遮挡不删除既有测量；
新增缺失格的插值可使用前端保留的原始测量邻域，当前矛盾回波可立即否决旧地面。
训练与插值域不使用预测值。每次输出仍要求及时的原始扫描，以检查新负证据。
这里沿用前端融合测量的有效性，并未建立逐格观测年龄模型，不能宣称已完成动态环境校准。
新出现的高点、坑和碰撞信息仍可否决支撑。相邻格存在超出可过台阶高度的跳变、
或紧邻已检出的碰撞单元时，该单元不用于训练平滑地面模型，其原始测量仍保留用于拒绝危险姿态。
训练点筛选采用相邻单元检查，不能用大窗口的高差直接排除连续坡面。
测量身份、原始高度、预测高度和初始假设分别发布。

### 12.2 后验和几何风险公式

有限维特征由二次趋势与高斯径向基组成，记训练设计矩阵为 \(\Phi\)，
单元观测方差为 \(R_{ii}\ge (0.02\,\mathrm m)^2\)。趋势采用弥散先验，
径向基系数采用高斯先验，精度矩阵为 \(\Lambda_0\)。需要趋势满秩和 Cholesky 分解成功：

\[
\Lambda=\Phi^TR^{-1}\Phi+\Lambda_0,
\quad \hat\beta=\Lambda^{-1}\Phi^TR^{-1}z,
\quad \mu_q=\phi_q^T\hat\beta,
\quad B=\Phi_qL_\Lambda^{-T}.
\]

因此共享有限维后验协方差为 \(BB^T\)。这是权重空间高斯回归公式，
可参照 [GPML 第二章](https://gaussianprocess.org/gpml/chapters/RW2.pdf)。
本实现另加一个独立的空间相关模型差异项：

\[
\Sigma_{ij}=(BB^T)_{ij}
 +d^2\exp[-\|x_i-x_j\|^2/(2\ell_d^2)],
\quad d\ge0.01\,\mathrm m,\quad \ell_d=0.20\,\mathrm m.
\]

`d` 至少取训练残差的均方根。这个额外协方差是资格模型的假设，
不是严格重新条件化后的无限维 GP，也不是从独立测试集得到的置信区间校准。
与此前完全未知相关性的误差模型相比，这是更强的空间结构假设，必须用独立地形数据检验。
保持相同边际方差而改用该协方差，不能被描述成“无条件更安全”。

对坡度、残差或台阶线性量 \(g=w^TH\)，标准差界为：

\[
s_g\le\sqrt{\gamma w^T\Sigma w}+\sigma_0\|w\|_1.
\]

最后一项仍允许任意相关性。高斯尾概率用 `erfc` 计算，避免大量小概率相加时
`1-Phi(x)` 的浮点消减。可选的张量参考实现另支持残差跨度的两两差分证书：

\[
P(\max_i r_i-\min_i r_i>h_{\max})
\le\sum_{i<j}P(|r_i-r_j|>h_{\max}).
\]

默认 CUDA 融合实现使用逐点充分条件，不启用这项可选的两两差分收紧。
路径和制动检查仍使用并集上界，不将相邻姿态的安全概率相乘。
状态0.05、局部路径0.10、制动0.05三个预算没有提高，也不代表整段任务的失败概率保证。

### 12.3 可用域、启动与显示

插值要求位于实测源凸包内、距离原始回波或融合实测单元不超过显式设置的范围（默认0.75米；当前共享仿真资格允许显式设为1.25米），
并通过方差、原始测量一致性和负证据检查。单侧外推不放行。
传感器造成的车身下方大盲区可能超出这个范围；只有显式开启 `stable_stance` 时，
通过姿态稳定、周围地面一致性和离地高度检查的固定初始足迹，才可提供条件支撑。
这部分继续标为 `startup_prior_used`，不能标成实测或随着车辆扩大。
当前共享分支不支持旧的地面历史选项，组合使用会明确报错。
前端没有逐格实测时间戳，故 `gp_conditioning_age` 为未知值，不能伪报零龄；
`gp_completion_age` 仅表示当前负证据扫描与地图的时间差。
共享分支还保留空间负证据：低于原实测地面超过台阶限值的单元必须经过3个不同扫描时刻的
实测地面清除观测才能重新考虑。缺测、预测高度、重复地图回调不用于清除。
单个这样的向下回波即移除该格支撑；清除时每帧至少一个与地面
相差不超过0.05米的回波，且同格没有矛盾点，才算一次见证。

共享仿真分支为GPU前端启用下层地面语义：已有实测地面时，高于该地面0.05米
以上的点不再直接抬高地面均值。正高度回波增加独立当前占据，而不永久撤销先前实测地面；
共享分支的原始碰撞检查按0.18米台阶限值保持单个有效高点的否决，障碍存在时仍不能穿越，
防止车辆把新障碍物当作平地通过。尚未测量的单元仍按真实回波初始化；真实台阶、
下陷与坡面不能由这一规则平滑掉。控制输入资格脚本
`scripts/sim/checks/terrain_ground_qualification.py` 会启动实际CUDA节点验证这些边界。
该选项为 `elevation.preserve_measured_ground`，节点默认关闭，由地形启动文件在
`shared_gp` 且 `use_sim_time=true` 时自动配套开启。旧边际模型及实车默认配置保持原行为。

前端的 SE(2) 代价是整车足迹量，不能作为地面单元的占据证据再次膨胀。
共享地面模型的硬否决来自原始立柱、矛盾高度和测量不一致；随后对整个足迹重新验证
碰撞、坡度、台阶和概率预算。原启发式风险层仍保留，但不再以其任意航向最大值删除实测平地。

共享分支只计算一份近场后验，并供导航和 RViz 高程显示共同使用。
它不再额外运行一个异步全图 GP 来展示不同的预测结果。
`gp_mean`、`gp_latent_var` 对应当前模型；`probability_elevation`、
`probability_variance` 是实际进入风险传播的数据，原始测量层保持独立。
实时性、绕障到达和动态避障仍以整运动窗口及物理轨迹验收，不能由公式或单元测试替代。

### 12.4 分模块复现入口

以下是仿真资格分支，不是实车启动命令。固定初始假设及共享模型须显式开启。
同一工作区的四个终端按顺序执行；只由地形终端开启一个共享 RViz。

```bash
scripts/sim/start_simulation.sh --scene-profile light --map-asset none --nav-test-scenario detour
scripts/sim/start_mapping.sh rviz:=false
scripts/sim/start_terrain_analysis.sh terrain_backend:=gpu fsgp_gpu_backend:=cupy prediction_backend:=feature_sgp gp_complete_supported:=true probability_model:=shared_gp probability_gp_max_distance_m:=1.25 startup_support_mode:=stable_stance
scripts/sim/start_planning_control.sh chance_allow_gp_completion:=true chance_allow_joint_model:=true chance_allow_startup_prior:=true reverse_recovery_enable:=true
```

上述手动入口不会自动发送目标；不要同时运行键盘控制与规划控制。
精确复现7米绕柱、真值净距与全程时效检查应使用记录参数的资格脚本：

```bash
python3 scripts/sim/checks/pipeline_smoke.py --domain 89 --gui --rviz-view height --prediction-backend feature_sgp --gp-complete-supported --probability-model shared_gp --gp-support-distance .75 --startup-support stable_stance --reverse-recovery --trial-scenario detour --trial-timeout 65
```

不要与前面四终端同时启动。不同 `log/modular_smoke_*` 中的源码快照才是该次试验的版本依据。
动态横穿、清除、上下坡和Mars短程的各次资格以记录中的参数、源码和原始轨迹为准；
单条静态路线不提供其他场景的资格，也不提供实车或全场景高成功率保证。
