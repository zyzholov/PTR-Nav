# 条件动态风险模块：模型、许可关系与资格边界

本模块解决的是旧可达范围把所有未来停车位置同时保留、导致所有候选被拒绝的问题。它是新增的**显式仿真资格模式**，尚不能代表已校准的行人预测。默认 `reachable` 和实车配置保留。名义跟踪仍是 PP/Stanley 混合控制，未移植 MPPI。

## 1. 输入与估计

输入来自实际纠正点云构成的完整实测占据，不读取仿真物体真值、预设轨迹、未来速度或人工航点。唯一关联、形状、三帧中心速度、位移及残差门限均保留。只有通过这些检查的圆形中心运动假设进入高斯模型；不合格形状使用原可达几何，不能被删除。未确认身份仍为 id=0，不能解除已确认但缺测的身份。

状态为 \(s=[x,y,v_x,v_y]^T\)，在原扫描源时间建立后验：

\[
s_{k+1}=F(\Delta t)s_k+w_k,\quad
F(t)=\begin{bmatrix}I&tI\\0&I\end{bmatrix},\quad
Q(t)=q\begin{bmatrix}t^3I/3&t^2I/2\\t^2I/2&tI\end{bmatrix}.
\]

位置观测噪声 \(R=\sigma_z^2I\)，采用 Joseph 形式更新协方差，避免减法产生非正定矩阵。初始位置观测只使用一次。当前原型 \(\sigma_z=0.03\) m、\(q=0.04\) m²/s³ 是**模型参数假设**，不是由独立标定集得到的人体运动概率。三至四帧的短历史不能可靠识别任意转向意图，也不能解释为语义识别。

预测均值 \(F(t)\mu\)，预测协方差 \(F(t)PF(t)^T+Q(t)\)。协方差不能丢掉位置与速度之间的相关项。时间倒退、非有限数据、非 PSD 协方差和过期源均拒绝；不修改时间戳来通过源龄门限。

## 2. 为什么不直接把逐帧风险相加

相邻预测时刻来自同一个位置/速度后验，不能视为独立事件。把所有边缘碰撞上界求和虽然是并集上界，却会将同一次横穿在大量时刻重复计入。开发回放中该版本仍将全部候选拒绝，原始记录保留在 `log/neos_acceleration_envelope_20261110/geometry_gaussian_weak_v2.json`。

新实现逐个对象采样完整 Markov 轨迹，计算事件

\[
C_j=\{\exists k:\ \mathcal B(x_k,y_k,\psi_k)\cap\mathcal O_{j,k}\ne\varnothing\}.
\]

这里 \(\mathcal B\) 是原非对称矩形车身及唯一安全余量；\(\mathcal O\) 保留实测圆形半径、测量关联余量。`C_j` 是**整条预测轨迹是否碰撞**，而不是每一帧的独立碰撞。CPU/CUDA 使用同种子算法与双精度几何进行一致性检查。

高斯分支先验证拟合圆包含全部实测占据格方块，随后使用该圆和位置/速度后验；不再额外复制旧可达模型中的注册圆及速度误差圆。它是显式的条件模型改变，不是分布无关的几何保证。非高斯资格对象的原可达检查不变。

离散时间余量使用实际最大采样间隔的一半，乘以物体 4.5 m/s 速度域与车身边界速度上界之和；20 ms 密集轨迹对应 10 ms 余量，40 ms 对应 20 ms，稀疏输入必须扩大余量。高斯过程本身具有无界尾部，因此这一计算是扩大离散姿态下的条件模型风险，**不能冒充无条件的连续时间人体安全定理**。物理复测仍用独立实际几何判定碰撞。

## 3. 采样误差不是预测误差

对对象 j，N 条轨迹中 K 条碰撞，K/N 只是估计量。使用单侧精确二项上界

\[
u_j=\operatorname{Beta}^{-1}(1-\alpha_j;K+1,N-K),\qquad
K=0:\ u_j=1-\alpha_j^{1/N}.
\]

\(\alpha_j\) 是有限采样导致上界失效的概率，**不是碰撞概率**。零采样碰撞也不能报告风险为零。数学覆盖依赖所指定采样模型及 iid 抽样假设；实现使用伪随机数，模型失配不受该区间保护。

多个对象使用 \(U_D=\min(1,\sum_j u_j)\)，并将采样 α 在对象间分配。它不需要对象间相互独立。一次节点运行第 n 次检查使用 \(\alpha_n=10^{-4}/[n(n+1)]\)，其总和不超过 \(10^{-4}\)；各候选和最终重验证使用新样本，不能用经过挑选的样本直接认证。日志记录基础种子、检查序号、模型参数和上界。

低样本量预筛查只影响哪些候选被淘汰，不允许输出控制。最终许可使用默认 8192 条样本及上置信界。GPU 初始化/JIT 在启动时完成，不能等到紧急横穿才首次加载。CPU 模式提供逻辑托底，但其时延须单独测定，不能默认具备相同实时性。

预筛在全部候选的实际时间点并集上，为每个物体采样一次相关随机轨迹，供所有候选复用。通过 F/Q 的 Markov 合成关系，每条候选仍服从指定的单轨迹模型；改变的是不同候选之间的抽样耦合，因此与旧候选独立种子版本不要求逐个样本计数相同。候选排序互换不应改变同一候选的预筛结果，CPU/CUDA 对同一共享采样应一致。内存超过 256 MiB 或时间并集超过 4096 点时拒绝本次预筛，不能丢对象或静默缩短时域。最终认证仍独立采样，不复用经过挑选的预筛轨迹；GPU 启动预热覆盖共享预测和最终认证两条路径。

## 4. 与 GP/SEB 地形风险的关系

动态上界不取代地形推断，不生成自由地面，不删除碰撞格。对所选动作仍要求完整车身几何、地面支撑、源龄和版本一致，并保持原约束：

\[
U_{G,\mathrm{pose}}+U_D\le0.05,\quad
U_{G,\mathrm{path}}+U_D\le0.10,\quad
U_{G,\mathrm{selected\ brake}}+U_D\le0.05.
\]

原立即停车策略的地形上界仍独立不超过 0.05；它不授权一个会被运动物体撞到的停车动作。GP 的源事件去重、条件高程支撑和联合风险账本没有改成启发式代价。上述并集关系不需要地形误差与动态对象独立。

仿真新模式采用至少 **3 s 滚动时域**，生成最长 6 s 的有限候选，截取完整停车后至少 0.20 s 的零速尾段；执行过程每次仍检查接下来的至少 3 s，不能越接近原截止时刻就只检查几帧。它改变了旧版部分前行动作的“停车后额外 1.2 s”尾段，不应描述为完全相同的规划问题。额外加入短距离 S 形侧绕候选，车辆曲率与 1.33 m/s 运行上限不变。0.20 s 执行响应和仿真观测标准差 0.018 m 都需显式启用，默认延迟 0.35 s、观测标准差 0.03 m 保留。

地形后验有效范围必须与上述动作范围匹配。`shared_gp_posterior_radius_m` 表示以滚动栅格中心为中心的**方形计算区域半宽**（1–5 m，旧默认 3 m），不是缺失地面的外推许可距离。扩大它会改变训练区域和核基函数，属于模型配置改变；不能称为完全不变的后验。原始实测似然、障碍/台阶否决、最大支撑距离、最大外推距离和风险上限仍逐项检查。地图发布该参数，冻结回放按原配置重建，禁止把改变半宽后的结果冒充原后验重现。

`possibleEarlyStops` 是同时列举多个可能停车位置的优先级集合，不是一条可执行轨迹。它保留原可达几何检查，不能把其重复未来时刻误当作高斯执行策略。冲突记录的几何解除同样不等于地形运动许可。最终命令仍需刷新当前状态和源数据再验证。

## 5. 启动与证据解释

仿真规划模块可显式选择：

```bash
scripts/sim/start_planning_control.sh navigation_profile:=neos_joint_sim \
  live_motion_prediction_model:=gaussian_joint_cuda
```

CPU 对应 `gaussian_joint_cpu`，原几何模式为 `reachable`。该命令只启动规划模块，仿真、建图和地形模块仍按四模块顺序分别启动。新模式的输入、许可和外推适用域均需资格验证，未通过时不作为推荐默认方案。

开发历史回放 `joint_replay_summary.json` 在首次强运动观测处找到两条小于 2% 条件动态风险上界的候选，但它**没有证明地形合格、下发成功或物理到达**。原型单元检查及 CPU/GPU 一致性也不能替代导航资格。完整结果和失败继续记入 `DYNAMIC_INTERACTION_REPAIR_20261109.md`，不以通过数学检查宣告系统完成。
