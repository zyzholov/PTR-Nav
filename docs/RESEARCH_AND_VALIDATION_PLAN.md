# 概率地形导航：实现审计与研究验证主线

日期：2026-10-20，代码状态更新至2026-10-21。本文是审查稿，不是已完成的论文实验报告。
本轮仅获准小规模资格测试；正式数据划分、外部对比和批量实验仍须审阅。

## 1. 先回答当前实现是什么

| 问题 | 代码事实 | 不能推出的结论 |
|---|---|---|
| 跟踪器是 MPPI 吗 | 默认 `tracking_controller=auto`、`use_mppi=false`，选择 Pure Pursuit/Stanley 混合跟踪 | 不能写成已部署 MPPI |
| 原采样控制器是什么 | 对候选控制序列扰动，选代价最小的可行样本；现正名为 `sampling_mpc`，CPU 执行 | 不是基于重要性权重更新的标准 MPPI；旧 `mppi_*` 参数仅兼容 |
| 概率导航是否实现 | 高程不确定性传播、SE(2) 姿态约束、局部路径并集预算、制动包络约束均有代码 | 不等于模型已校准、整任务失败率已获保证或动力学导航已验收 |
| GP 是否已用于默认导航 | 仿真地形脚本默认启用当前扫描约束的局部GP补全，规划默认允许仿真GP支撑；通用节点与实车的导航补全仍需显式授权 | 背景全局GP候选不自动进入导航；不能把有输出等价为可通行 |
| GPU 加速了什么 | CUDA 高程/原 SEB 前端、CuPy 几何概率计算；GP 可选 GPU 后端 | 搜索和当前跟踪器不因此变成 GPU 算法；整链实时性须另测 |

标准 MPPI 的算法依据见 [Williams 等的原论文](https://arxiv.org/abs/1509.01149)。
本工程没有为了名称一致而临时自造另一个 MPPI。需要该对比时，应优先资格验证
[Nav2 官方 MPPI](https://github.com/ros-navigation/navigation2/tree/main/nav2_mppi_controller)，
统一 Ackermann 模型、转向角/角速度接口、倒车、速度/加速度界限后再比较。

## 2. 科学问题和创新边界

### 2.1 已有工作必须承认

[SEB-Naver](https://arxiv.org/abs/2503.02412) 已有 GPU 的 SE(2) 地形评估和地形关联运动规划；
[FSGP-BGK 官方源码](https://github.com/ZJU-FAST-Lab/FSGP_BGK) 已实现特征稀疏 GP 与时空地形融合；
[STEP](https://arxiv.org/abs/2103.02828) 已研究不确定性感知地形评估、CVaR 风险和约束 MPC。
因此，“GPU 地形分析”“GP 预测”“概率风险导航”这些大类本身都不能作为本系统的首创。

ROS2 移植、Isaac 传感器、模块脚本、RViz、CPU 回退是工程工作；
不能把 Cauchy-Schwarz 方差界、Boole 并集界或高斯尾概率包装成新定理。

### 2.2 当前可以提出、但尚待证明的贡献假设

**H1，来源约束的一致风险接口。** 将实测、邻域恢复、预测和未知分开，
由具有明确语义的高程不确定性构建方向相关几何越界上界；
规划、重规划和制动输出使用同一约束，而不是各模块任意解释归一化分数。
这是候选系统/工程贡献。需要证明它减少危险漏检，同时没有因过度保守而丧失可用性。

**H2，相关误差下有效且不过分保守的几何风险。** 当前只保存边际方差，
采用任意相关性的最坏界。若进一步利用可追溯的位姿公共误差与局部测量误差结构，
可能得到更紧的方向几何风险与路径风险约束。目前仅实现了显式仿真假设下
固定起始平面的共享误差传播，不能推广为普通地面的已知协方差模型。
是否形成算法研究贡献尚未证明；必须与最坏界、错误独立假设、同输入原 SEB 公平比较。

**H3，预测是否真正改善决策。** 合格 GP 支撑能否在不增加危险漏检的前提下，
增加可行路径检出率、减少观测等待？必须同时验证预测区间和最终几何事件，
不能用补全图更完整作为充分证据。当前有受控缺测与有限闭环资格记录，
但没有冻结测试集上的大批独立任务，H3尚无泛化提升结论。

**没有证据前，不写成三项已成立创新点。** 若 H2 不成立，仍可诚实定位为系统研究，
而不是把 H1 拆成多个“理论创新”。

## 3. 输入、输出和参考对象必须对应

```text
点云 + 位姿 -> 高程均值/方差/来源
            -> [可选 GP 候选补全]
            -> 航向相关几何约束概率上界 + 独立占据约束
            -> 有预算的局部规划/新地图复核
            -> 跟踪 + 制动安全检查 -> 车辆
```

| 被测对象 | 独立参考 | 主要问题 |
|---|---|---|
| 高程预测 | 独立密集扫描或生成器的真实表面 | 没观测到的位置预测准不准；输出多少；何处拒绝 |
| 高程不确定性 | 有参考的逐查询误差，或已知随机过程 | 区间是否过窄/过宽；失配在哪里 |
| 方向几何风险 | 独立解析表面的车辆足迹几何标签 | 坡、沟、台阶、窄柱是否漏检；航向是否起作用 |
| 概率上界 | 同一随机世界中独立实现的几何事件 | 是否低估；是否过松导致无法通行 |
| 规划 | 独立路径检查器及有可行解的控制场景 | 能否找到预算内路径；耗时、拒绝和失败原因 |
| 控制/动力学 | 真实状态、接触、姿态与停止记录 | 跟踪、响应、碰撞、失稳，而不是仅看规划路径 |

道路/室内原始数据天然稀疏时：参考无值处不能计算误差或给安全标签。
人为隐藏的测试点须在隐藏前有独立可靠参考；训练/参考的地面提取和栅格坐标须一致。
实测稀疏输入不能与采用另一套地面筛选器得到的参考直接逐图比颜色。

## 4. 指标字典

- 高程 RMSE/MAE/P95：仅在预先固定的、有独立参考的查询集上计算，单位米/厘米。
  拒绝点不能从分母悄悄删除；误差与有效输出比例必须并列。
- 预测区间：`mu +/- 1.96 sigma` 是高斯模型的名义 95% 高程区间。
  总宽度为 `3.92 sigma`，是竖向不确定性，不是地图大小。
  实际覆盖率是被这个区间包含的参考高程数/可评价区间数。
- 地图支撑率：有合格输出的查询数/全部预定查询数；不是上一个指标。
- 危险漏检率：被独立参考判定危险、却被方法接受的姿态数/参考危险姿态数。
  未知、误报、保守拒绝分别统计，不能把未知全算正确安全。
- 上界有效性：比较经验几何越界频率及其统计置信区间与预测上界。
  上界不要求等于实际频率；还必须报告松弛和拒绝率。
- 路径预算：当前局部路径离散事件集合的并集上界，不是整次任务的成功率。
- 实时性：端到端数据年龄及模块墙钟 P50/P95/P99、截止期违反率、实时系数、GPU 显存。
  不能只报 CUDA 核函数时间，不能把仿真时间频率当墙钟实时频率。
- 失败案例：超时、无支撑、预算不足、几何无解、碰撞、跟踪失败分开。
  耗时箱线图包含所有尝试；超时须标记删失，不能只画成功样本。

## 5. 分层实验设计（待批准，不执行批量）

| 编号 | 场景/输入 | 自变量 | 固定条件及输出 |
|---|---|---|---|
| T1 高程泛化 | 丘陵/森林/废墟/道路/室内，独立地图划分 | 随机稀疏、连续孔洞、几何遮挡、单侧外推 | 同一隐藏坐标、噪声、点数预算；误差、区间、输出域 |
| T2 方向危险 | 倾斜平面、沟槽、孤立台阶、窄柱和组合 | 坡角/台阶高/沟宽/车辆航向 | 同一车辆足迹和通过极限；危险漏检、未知、误报 |
| T3 概率传播 | 已知边际和协方差的受控高程误差 | 公共位姿误差、空间相关长度、测量噪声 | 一个误差实现作用于整条路径；上界违反和保守程度 |
| T4 时序更新 | 连续部分观测、障碍出现/消失 | 数据年龄、观测覆盖、运动速度 | 固定场景真值；更新时间、残影、静态误清、假支撑 |
| T5 规模/性能 | 地图宽度、分辨率、航向层、GP 支撑点 | CPU/GPU、订阅可视化开/关 | 同机同输入含搬运；P95/P99、显存、输出一致性 |
| N1 地形规划 | 同一已冻结地形图的多组起终点 | 风险预算、方向、倒车、路宽 | 隔离感知误差；可行解检出、耗时、路径预算与几何 |
| N2 重规划/控制 | 新障碍、横穿、急停、坡道、倒车 | 更新延迟/目标距离/速度 | 接触真值；首次安全反应、停止距离、跟踪误差 |
| N3 端到端 | Isaac 实际点云与物理底盘 | 上述代表工况 | 先资格后批量；不得用点云回放代替动力学证据 |

T1 至 T5 是主体，N1 至 N3 说明上游对后续决策是否有实际价值。
不以导航成功率替代地形评估，也不以地形误差小替代车辆安全。

规模建议须按独立地图分组，而不是按点数充数。正式首批可审阅为每类至少 20 张未见地图、
每图固定多组隐藏/噪声种子；N1 每张冻结图多组起终点，N3 先少量资格再定规模。
这是设计建议，不是“已完成数量”或通行的学位论文硬性标准。
测试前冻结划分与门槛，验证集调参后不回看测试集挑效果好的样例。

## 6. 外部对比与消融分开

### 外部方法

| 层次 | 优先对象 | 公平性条件 |
|---|---|---|
| 原始点云完整地形模块 | EM、SGP、BGK、原版 FSGP-BGK、本工程 | 原作者源码固定提交；统一原始输入、参考和算力限制；保留各自原生输出语义 |
| 同高程输入的几何评估 | 原 SEB 与本工程；ETH 能输出适用几何量时另列 | 共享 DEM，不把 ETH 代价硬解释成概率；方向专项保留查询航向 |
| 整体导航 | 原版 SEB-Naver，资格部署后的 PUTN/合适车式规划器 | 相同车体、接触、起终点、硬约束和计算预算；不是拿本工程开关代替外部方法 |
| 风险导航文献定位 | STEP | CVaR 与机会约束不是同一指标；无作者可运行源码时只作研究比较，不伪称复现 |
| 轨迹跟踪 | 现混合器、单独 Pure Pursuit/Stanley、正式 Nav2 MPPI | 同一参考轨迹、动力学/接口/延迟；先证明可运行再加入成绩表 |

EM 等输出高程但不输出方向概率时，只比较共同对象；不虚构方法不存在的概率层。
共用高程评价器的“受控模块比较”与原始点云“完整流水线比较”须分别命名。
本地部署状态、源码版本及审阅门仍以上级 `terrain_baselines/terrain_review` 为准。

### 内部消融

固定同一测试划分、输入及控制器，分别关掉：方向建模、不确定性、路径预算、
制动预算、来源限制、合格 GP 支撑、时序清除。每项只回答对应机制的作用。
不安全开关只用于隔离沙盒，不进入实物默认配置。
CPU/GPU 是后端一致性/性能比较，不算算法新贡献的消融。

## 7. 图表必须回答问题

1. 同坐标/色标的输入、参考、预测、未知域、误差、危险标签，解释每幅图评价域。
2. 按独立地图的误差/耗时箱线图、P95/P99/失败数；不要只画均值柱状图。
3. 航向-坡度/台阶高度的危险漏检与拒绝热图；同一高度不同航向的案例。
4. 高程区间实际覆盖率和宽度并排；模型越界上界与实际频率另画，不能混用。
5. 时序更新曲线：静态保留、动态残影面积、数据年龄和首次响应。
6. 规划/控制图：真值轨迹叠加、速度/转向、横向误差、风险预算、规划耗时。
7. 三维图仅辅助展示几何和不确定性，缺测不跨孔连面。
   三维柱状图可作补充，但不能遮住样本量/失败率，也不能代替耗时分布。

图例写中文、单位和分母，样例按预定 ID 选择，不按观感挑选。
正式统计以地图/任务为独立单位配对比较，重复种子不伪装成独立地形；
使用地图簇 bootstrap 或相应层次模型，测试失败保留完整日志和原因。

## 8. 当前资格门与阻断项

已运行的小规模结果单列在 [资格记录](QUALIFICATION_20261020.md)；
它们不是上表正式批次，不推导泛化成功率。

必须优先处理：真实稀疏观测的可用支撑、最坏相关界的保守性、
重复足迹事件在搜索过程中的累计、连续运动与离散航向的误差、
模型方差与真实误差的吻合、制动参数真实性。
当前没有全任务风险账户，也没有连续运动安全定理。

完成顺序：资格/失败定位 -> 模型与工程修正 -> 资格复验 -> 审阅正式方案 -> 批量地形 -> 导航扩展。
默认配置仍应失败关闭；不能降低方差、给未知区补“安全”、放宽预算来把不通过包装成通过。
