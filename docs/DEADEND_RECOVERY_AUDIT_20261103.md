# 死角回退与车辆参考点排查（2026-11-03）

这是定向故障修复记录，不是成功率报告。每个物理版本保留原始失败，源码在同组物理检查期间冻结；不合并不同版本估计成功率。未推送 GitHub。

## 已确认的基础错误

Hunter 的 `base_link` 位于后轴前方 0.2078 m。旧规划、控制和刹停模型却直接把它作为后轴中心。FAST-LIO 发布的车体坐标无需平移修改，错误位于车辆运动学消费端。

令后轴纵向速度为 v，前轮等效转角为 δ，轴距 L=0.549185 m，车体航向为 ψ，a=0.2078 m。正确关系是：

```
ω = v tan(δ) / L
ẋ_base = v cos(ψ) − a ω sin(ψ)
ẏ_base = v sin(ψ) + a ω cos(ψ)
ψ̇ = ω
```

四份及后续两份已有真值轨迹的独立读取均支持这个几何关系：拟合 `v_y_body/ω` 约 0.2081–0.2088 m。配置采用 URDF 的 0.2078 m，不采用测试拟合值。真值只用于观察，不回灌定位、建图或导航。证据、筛选条件、文件哈希见 [真值参考点审计](../log/body_reference_audit_20261102/truth_reference.json)。

所有地图、占据碰撞、概率足迹和发布轨迹仍用 base_link 位姿。公共运动学实现区分后轴纵向行程与车体曲线行程：`ds_base = sqrt(1+(aκ)^2) ds_rear`。已统一到格点与拓扑搜索、正反向圆弧、Dubins/Frenet连接、里程计预测、混合跟踪、动态预测及制动滚动检查中。车身姿态约束在后轴弦上检查，完整碰撞包络继续放在车体参考点上。

## 死角恢复的执行规则

1. 普通前进搜索失败时，允许寻找受曲率限制的倒车/前进组合。
2. 在没有可证明前进出口时，可执行不超过 2.5 m 的有界退让，再停稳重新搜索；该动作不等于找到出口。
3. 多挡拓扑路线中的后续腿仅是几何意图。每次停稳后按最新地图、完整车身、支撑和局部联合风险重新认证下一执行段。
4. 最新候选允许执行下一腿**已认证的连续前缀**，保留剩余同挡尾段；不能跳过未知部分直接切入下一挡。原先“下一腿整段不合格便丢弃整个退出意图”的规则过度约束了滚动执行。
5. 数据过期立即停车；仅可短时保存几何意图，恢复时不能使用旧安全证明。空间坐标/契约失效与短暂消息延迟分开处理。
6. 每个实际控制周期继续检查实测速率下的完整制动包络。保持保护包络前/后/半宽 0.68/0.58/0.50 m，以及状态/局部路径/制动预算 0.05/0.10/0.05。未知区域没有被标记为免费通行。

这些预算是条件模型上界，不是经过校准的任务成功概率；滚动段的局部账户不等于整个任务的联合保证。跟踪器仍是混合 Pure Pursuit/Stanley，不是 MPPI。

## 下一轮针对性验证

新增 `deadend_entry`：从巷道外进入，进入后前方实体障碍连续移动封闭出口；车辆必须利用先前走过区域回退，绕行到同一个最终目标。与“启动即身处后方完全未知的死角”分开，不能为了倒车而假设未知后方安全。

该场景只下发一次最终目标。真值观察器还要求实际入巷、障碍闭合和至少 0.8 m 实际倒车行程；仅目标到达、控制器发出负速度、或者根本未进入巷道，都不能冒充恢复测试通过。几何、触发时刻和真值仅供场景与独立记录器使用。

滚动前缀恢复版本的物理结果在取得后补充。新增的未知尾段、即时未知、碰撞、过期、坐标失效和换挡次数回归须先通过，之后才启动物理检查。
